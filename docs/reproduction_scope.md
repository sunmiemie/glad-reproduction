# 复现范围与差异登记

## 使用的来源

- 论文：Guo 等，Global-Local MAV Detection under Challenging Conditions based on Appearance and Motion，https://arxiv.org/abs/2312.11008。
- 作者基础代码：`WindyLab/Global-Local-MAV-Detection`，提交 `ab9fd85e60c3f4cb61d79ea8ecd19d9362f5b380`。
- YOLOv5：v6.0，提交 `956be8e642b5c10af4a1533e09084ca32ff4f21f`。
- 使用作者发布的 `yolov5s_GLAD.pt`、`yolov5s_GLAD-crop.pt`、`Net_best.pth`，未重新训练。

作者 README 明确表示当前公开的是基础代码，完整 Kalman Filter 和 Adaptive Search Region 尚待公开。因此本项目不是作者未公开程序的逐行移植，也不能证明所有内部参数与论文一致。

## 明确的工程选择

1. **相对速度滤波参数**：帧为时间单位，`Q=0.1I`、`R=4I`、初始协方差 `diag(25,25,4,4)`，采用常加速度状态转移。发生缺失后，累计相机变换更新最近真实观测的参考位置，重新检测到目标时使用残余位移/间隔帧数作为平均速度观测，观测噪声随间隔增大。这些参数与缺失更新细节未在论文中完整给出。
2. **候选关联**：局部使用置信度排名和距离排名之和，固定并列规则，避免公开脚本随候选顺序变化。距离门限默认 `50 + 4×lost`。这一具体融合规则及门限扩张是本项目的工程实现。
3. **运动分割阈值**：全局 `5 + alpha×TA + beta×TM`，TA 为未补偿两帧平均绝对灰度差，TM 为有效匹配的平均位移；`alpha=1,beta=0` 是显式工程默认值。局部阈值 4 来自公开演示。
4. **运动一致性**：围绕圆均值计算角度方差，单位 rad²；幅值方差单位 px²；阈值均为 .8。最小平均运动幅值为全局 1 像素、局部 .6 像素。公开代码使用带符号均值作分母的变异系数，本项目改为论文描述的方差并修复角度环绕；不宣称它们数值等价。
5. **分类器架构**：公开文件同时定义 Net 和 MyNet，但推理实际调用的是两层卷积 Net。`Net_best.pth` 与 Net 匹配。本项目遵循真实权重，不将论文示意图直接替换成无法加载该权重的网络。
6. **低纹理图像退化**：无法可靠估计 H 时，预测采用未补偿位移；运动分支停止输出候选，外观分支继续工作。纯天空等场景可能因此主要依赖外观，不能保证提升召回率。
7. **候选和坐标修复**：使用当前帧进行候选分类；角点和 LK 源图一致；无效边界用布尔掩码清零，防止 uint8 减法下溢；目标状态始终保留全图坐标，ROI 平移后重新换算局部坐标。
8. **全局运动分支**：采用论文所述的运动候选 + CNN 后直接输出结果，不采用 `GLAD.py` 中额外 detector3 再确认。公开的 `GLAD_MC.py` 与基础脚本也并非完全相同。
9. **速度口径**：CPU、PyTorch、逐帧完整运行，与作者 TensorRT、NVIDIA 设备和测试视频条件不同。没有进行视频抽帧，也不以重复预测框增加检测帧数。

## 完成与尚未完成

已完成：独立仓库、可下载校验的官方模型、可运行视频推理、全局/局部/外观/运动流程、预测开窗重建、结构和几何测试、本机真实视频输出。

尚未完成：原训练数据全量获取和数据划分核对、三套模型重新训练、论文各数据集完整 AP 评估、作者 NVIDIA 板卡上的 TensorRT 性能对齐。当前结果不是这些实验已完成的证据。

## 后续严格复现实验

1. 获取论文使用的 ARD-MAV、NPS-Drones、Drone-vs-Bird 视频与真值，逐项核对版本、训练/验证/测试序列，避免把不同的 ARD100 工程数据目录直接视为论文 ARD-MAV 划分。
2. 先对已发布权重做完整测试集评估，记录逐帧检测和 IoU，再按论文评价协议计算指标。禁止把输出框比例当召回率。
3. 训练全局 YOLOv5s；用训练集目标附近的 320×320 裁剪及对应框训练局部 YOLOv5s；用候选正负样本训练 32×32 分类器。分类器论文示意与公开权重结构的差异应在实验中单独登记。
4. 使用同一测试集依次比较全局外观、全局/局部外观、加入运动兜底、加入预测与自适应 ROI，避免多个改动混在一个结果里。
5. 在目标板卡重建匹配设备和 TensorRT 版本的 engine，固定输入、精度、功耗模式及计时口径后评估。上游 Linux `.engine/.so` 不能直接视为 Windows 或其他设备可用模型。
